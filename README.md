## fourth-script.user.js
### Казинака

Небольшая развлекательная мини-игра для браузера, работающая через Tampermonkey.

- Все монеты полностью виртуальные.
- Монеты нельзя купить за реальные деньги, продать или вывести.
- Баланс хранится локально в браузере.
- Игра не взаимодействует с реальной экономикой Legion Game.
- Никаких платежей, денежных выигрышей и материальных призов не предусмотрено.

Проект предназначен исключительно для развлечения во время скучной копки шахты ⛏.
